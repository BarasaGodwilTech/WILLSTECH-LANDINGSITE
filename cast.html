Phone to TV Screen Cast

Cast your phone screen to your analog TV via laptop connected with VGA. Use this web app on both devices to establish a WiFi connection.

Setup Instructions

1

Connect Laptop to TV

Connect your laptop to your analog TV using a VGA cable. Make sure the TV is set to the correct input source.

2

Connect to Same WiFi

Ensure both your phone and laptop are connected to the same WiFi network for screen casting.

3

Open this Page on Both Devices

Open this webpage on both your phone and laptop. Follow the instructions below to start casting.

How This Works

  • This solution simulates screen casting using WebSocket technology to send data between devices on the same network.
  • In a real implementation, you would need a server to relay messages between devices. For now, this is a simulation.
  • To implement this for real, you would need to:
    1. Set up a WebSocket server on your laptop or a local server
    2. Use WebRTC for actual screen sharing from your phone
    3. Ensure both devices are on the same WiFi network
  • For now, this demo simulates the casting experience with sample content.
